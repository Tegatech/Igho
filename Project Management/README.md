## Group standards

Igho inherits The24thGroup engineering standards: clean architecture, provider abstraction, API consistency, workspace scoping, auditability, secure session handling, strict typing, test gates, structured logging and documented evidence.

Koroko-specific requirements are not inherited automatically. Igho-specific decisions take precedence when recorded in the implementation baseline or an approved ADR.
